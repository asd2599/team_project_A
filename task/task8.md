## 📌 목표

로컬환경(`localhost:3000`)에서 다마고치가 살고 있는 건 의미가 없습니다! 다른 사람에게 이 주소를 보내 링크 접속이 되도록 배포(Deploy)하고, 마지막 오류를 방어합니다. 프로젝트의 마침표는 README(문서화) 임을 명심하세요.

## 세부 업무 내용 (팀 전체 집중모드)

### 1. 방어코드 (어택 테스트)

"사용자는 언제나 우리의 로직을 부수려 합니다."

- **DB -100 버그**: 스케줄러가 배분 차감을 과도하게 해서 `hunger`가 -5가 되었다면?
  -> Node 백엔드에서 `Math.max(0, hunger - 5)` 로 바닥을 쳐주거나, 차라리 상태(Status)를 0일때 'DEATH(죽음)' 으로 바꿔 렌더링을 흑백으로 돌리세요!
- **채팅 스페이스바 무한대 버그**: 텍스트 입력 없이 긴 여백 " " 만 입력하고 쏠 때 막기. (Task 7 프론트에 `!inputText.trim()` 적용함)

### 2. 무료 3종 세트 배포 (Deploy) - 초보자도 1시간 컷 가능!

1. **[프론트엔드 React] Vercel.com 배포**
   - 깃허브(Github)에 코드를 올린 뒤, Vercel 회원가입 후 내 깃허브 Repository를 연동 버튼 한 번만 누르면 30초 만에 `내이름어쩌구.vercel.app` 이라는 이쁜 도메인이 나옵니다!
2. **[Node.js / Python 백엔드] Render.com 배포**
   - 백엔드는 24시간 도는 서버가 필요합니다. Render.com 에 코드를 연동하여 `Web Service` 생성 모드를 통해 Node 와 Python 을 각각 올릴 수 있습니다. (무료 서버는 요청 안 하면 잠들어서 깨는 데 50초가 걸리니 주의!)
3. **[PostgreSQL DB] Supabase 배포**
   - 내 컴퓨터에 있던 엑셀표(DB)를 공용 네트워크로 올립니다! Supabase 사이트에서 무료 새 프로젝트를 뚫으면 호스트 비밀번호 링크(`postgres://어쩌구저쩌구`)를 줍니다. 이걸 백엔드의 `.env` 에 갈아 끼우면 클라우드 DB 연동 끝!
